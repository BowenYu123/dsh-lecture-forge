# 交付前自检清单

在调用 `lecture_audit level=full` 之前，逐项核对。任何一项“否”都不要宣称完成。

## 1. 覆盖

- [ ] `lecture_ledger action=stats` 显示 `pending = 0`。
- [ ] 每个 `blocked` 块都有具体 reason（不是“无关”两个字），且用户能在附录看到它。
- [ ] `merged` 块都指向一个真正包含该内容的 `covered` 块。
- [ ] 没有把整节内容压成一段摘要：每个 covered 块在正文里都能指出对应句子。
- [ ] 图、表、代码、脚注也覆盖了（不只是正文段落）。

## 2. 可追溯

- [ ] 来自素材的每个实质段落后有 `[S0x, p.N]` 或 `[S0x, §…]`。
- [ ] 跨页内容分别标注；没有用第一页的标记覆盖整节。
- [ ] 补充内容没有标素材来源，而是用 `> [!NOTE]` / `[!DERIVE]` 明确标出。
- [ ] 原文有误时用 `> [!WARN]` 指出，没有静默改写。

## 3. 解释与推导

- [ ] 原文“显然”“易得”的步骤已展开，每一步能说出用的定理/恒等式。
- [ ] 所有符号首次出现有定义；有符号表（公式多的讲义）。
- [ ] 定理/公式写了适用条件（连续、可微、有界、正定、边界条件…）。
- [ ] 有直觉解释（几何/物理图像、极限情形、量纲）。
- [ ] 每节至少 1 个完整例题（含思路）。
- [ ] 有常见错误清单（至少 3 条针对本主题的）。
- [ ] `brief.supplementary` 的每个桶都有实质内容，不是只出现关键词。

## 4. 公式

- [ ] 公式全部用 `$…$` / `$$…$$`；多行用 `aligned`。
- [ ] `lecture_build` 的 `mathErrors` 为空。
- [ ] 编号公式用 `{#eq-N}`，正文用 `[@eq-N]` 引用。
- [ ] 渲染后的页图里公式没有溢出、断行、缺字（看 `out/qa/`）。

## 5. 图

- [ ] 每个图都有 caption、登记了来源、正文有引用。
- [ ] 函数图来自 `lecture_figure plot`，不是手绘示意。
- [ ] 外部图有 license + author（strictLicensing）。
- [ ] 图在页图里清晰可读，没有被裁切或缩放过度。
- [ ] 图与正文数值/符号一致（轴标签、单位、符号）。

## 6. 代码与 Notebook

- [ ] 所有代码块可运行，依赖只用标准库 + numpy（或正文明确说明）。
- [ ] `lecture_build` 的 Notebook 执行 `executed == codeCells`、`failed == 0`。
- [ ] 代码输出是真实运行结果，不是手写。
- [ ] 关键推导用 `lecture_verify` 验证过（SymPy/NumPy），check 全 ok。
- [ ] Notebook 单元顺序可从头跑到尾（无隐藏状态）。

## 7. 构建与版面

- [ ] `out/lecture.pdf` 存在且页数 > 0。
- [ ] `out/qa/` 页图逐页看过：无空白页、无溢出、无重影、中文正常。
- [ ] 目录、图目录、页码、页眉正常。
- [ ] 未覆盖来源附录存在且内容正确。
- [ ] ipynb 能在干净环境打开（nbformat 4.5）。

## 8. 独立复核

- [ ] 另一个 subagent 通读了讲义与素材块，给出问题清单。
- [ ] 清单里的问题已修复，`lecture_audit action=record-review` 写入了 `verdict:"pass"`。
- [ ] `lecture_audit level=full` 返回 `ok:true`。

## 9. 回复用户

- [ ] 给出产物路径与页数/单元数。
- [ ] 给出覆盖统计与 blocked 说明。
- [ ] 说明补充了什么（推导、例题、图、外部资料）。
- [ ] 说明已知限制（扫描模糊页、原文缺失的证明等）。
- [ ] 给学习路径建议。
